# Контекстный seed-корпус v2

252 записи, 7 типов, EN/RU/ES/ZH и mixed EN/RU. Контракт модели остаётся
`context-json-v1`. Данные пересмотрены моделью по решению пользователя;
ручная разметка от него не требуется. Это **не независимое человеческое ревью**
и не подтверждение качества детектора.

| Split | Записи | Семейства |
| --- | ---: | ---: |
| train | 98 | 11 |
| validation | 48 | 6 |
| test | 64 | 7 |
| development | 42 | 6 |

В development находятся 10 известных пропусков, 24 производных примера и
8 строк спорного JSON-семейства. Эти 8 строк имеют
`provenance.review=model-review-quarantined`: их прежние label сохранены для
трассировки, а не как принятые обучающие метки. Семейство целиком изолировано,
включая переводы и безопасные контроли; четыре метки в журнале остаются `null`.

```sh
make validate-context
make prepare-context
go run ./cmd/context-corpus -reviews datasets/contextual/v2/review.json -require-reviewed
```

`review_method=model` и `quarantined_rows=8` входят в результат проверки.
CI проверяет manifest, привязку журнала к данным, группировку и отсутствие
development/quarantine в supervised splits. Автоматическая проверка подтверждает
согласованность артефактов, а не истинность модельных суждений.

- [REVIEW.md](REVIEW.md) — изменения, спорные решения и ограничения.
- `review.json` — решения по каждой записи и семейству, метод, протокол и SHA256.
- `initial-decisions.json` — первоначальные предложения по v1 до явной сверки
  с ключом в этом проходе; ограничения контекста ассистента раскрыты.
- `changes.json` — изменение family/split/primary_type для 42 записей.
- `manifest.json`, `review-result.json` — воспроизводимая структура/хеши и результат проверки.

V1 не изменён. Старые отчёты и pinned workflow lab-py продолжают относиться к v1;
они не становятся метриками v2. Модели и пороги на v2 не настраивались.
Test v2 сохраняет уже наблюдавшиеся v1 test-сценарии и не является новым holdout.
После карантина в validation нет authority-spoofing: это пробел покрытия,
который нужно устранить новыми независимыми сценариями, не возвратом спорных меток.
Происхождение данных, NOASSERTION и отсутствие реальных секретов унаследованы из v1.
