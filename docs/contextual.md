# Контекстный workflow v1

Источник данных — [lab PR #6](https://github.com/saifety-org/lab/pull/6).
`context.sources.lock.json` отдельно закрепляет commit/SHA256 контекстного корпуса
и Go-инструментов. Старый `sources.lock.json` и raw-text benchmark сохранены.

```sh
make bootstrap-context prepare-context train-context compare-context
# Для cached DeBERTa, без скачивания моделей:
uv run --locked saifety-lab bootstrap-context --onnx
uv run --locked saifety-lab compare-context --deberta
```

`prepare-context` скачивает только закреплённые файлы, проверяет установленный
Go-tool и сравнивает подготовленный manifest с опубликованным. При изменении
корпуса используйте новый cache или явно удалите старый: несовпадение SHA256 — ошибка.

Три native logistic-regression baseline обучаются на одинаковых train-сценариях
с фиксированными seed=1, epochs=40:

- `context`: канонический JSON context-json-v1 (задача + упорядоченные документы).
- `payload_only`: только текст документов, без задачи/меток/категории.
- `task_only`: только разрешённая задача — контроль возможной утечки метки из задачи.

Go остаётся единственной реализацией признаков и инференса. Для всех кандидатов
Python/Go scores должны совпасть с допуском 1e-12. Веса и метаданные связываются
с manifest и SHA256 всех splits; подмена артефактов останавливает сравнение.
Development не попадает в обучение, validation или test.

## Оценка

Единица сравнения — целый сценарий. У native ablations одинаковые train/evaluation
семейства, seed и бюджет FPR. Порог каждого кандидата выбирается только по validation.
Raw shipped и DeBERTa получают каждый документ отдельно с max-агрегацией; это
контекстно слепые reference-модели, сравнение не устанавливает универсальный рейтинг.
При превышении окна DeBERTa весь сценарий исключается для всех моделей.

Сканер измеряется отдельно, без перекалибровки: strict, каждый документ как tool-result,
два критерия — любое действие кроме pass и sanitize/block. Это не полная работа
приложения с исходными carrier/MCP-envelope, не агентный стенд и не доказательство
предотвращения атаки. Распределённые документы сохранены, но raw scanner baseline
не получает задачу и не собирает междокументный контекст.

Отчёт содержит per-type/per-language counts, precision, recall, FPR, общие исключения,
provenance и проверку authorization-pairs (одинаковый payload, разные разрешения).
Интервалы — exploratory percentile bootstrap целых семейств, seed=1, 1000 повторов;
переводы/контрпримеры не становятся независимыми наблюдениями. При одном семействе
или нулевой наблюдаемой вариативности интервал отсутствует: [0,0] не выдаётся за
доказательство низкой FPR. Малое число семейств ограничивает все выводы.

## Граница модели

Это первые **native ablations**, не обученный production multilingual transformer.
Линейный классификатор char-ngrams не гарантирует понимание отношений задачи и
инструкции. Context-json-v1 требует адаптера в приложении и отдельной проверки
совместимости; его веса нельзя использовать вместо raw-text production весов.
`compare-native` отклоняет такой кандидат, а raw transformer workflow не принимает
контекстные строки и не может экспортировать их с неверной raw-text меткой.

Следующий модельный шаг — независимая проверка/расширение корпуса и контекстный
multilingual encoder с отдельным экспортом/оценкой. Языковой роутер, перевод
с сохранением границ доверия и реальные agent/task-success метрики ещё впереди.
Результаты v1: [contextual-first-run.md](contextual-first-run.md).
