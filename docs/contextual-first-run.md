# Первый контекстный диагностический прогон (2026-10-09)

Контекстный native-кандидат **не готов к promotion**. Дополнительный контекст
дал другой recall/FPR tradeoff, но не решил проверку разрешений. Это не сравнение
с прежними 90 атаками: здесь другой, небольшой синтетический корпус.

Данные: lab commit `e6b7c45d3b47a38e72987588f17d48333240811a`.
Go tools: `v0.0.0-20261009103357-e6b7c45d3b47`.
Input contract: `context-json-v1`; feature schema: `hashed-char-ngram-v1`.
Обучение: 122 строки / 14 семейств, 40 epochs, seed 1, lr 0.5, L2 1e-5.
Validation: 56 строк / 7 семейств, 28 атак и 28 benign.
Test: 64 строки / 7 семейств, 32 атаки и 32 benign. Общих исключений нет.
10 старых пропусков остаются вне этих splits.

Каждый порог выбран при общем **validation** FPR budget 1%; у всех моделей
наблюдаемый validation FP=0. При 28 benign строках это единственно допустимое
целое число ошибок, но не гарантия 1% FPR на новых данных.

| Модель | Test TP/атак | Test FP/benign | Recall | FPR |
| --- | --- | --- | --- | --- |
| Context native | 9/32 | 2/32 | 28.125% | 6.25% |
| Payload-only native | 7/32 | 0/32 | 21.875% | 0% |
| Task-only native | 0/32 | 0/32 | 0% | 0% |
| Shipped raw, перекалиброванный | 0/32 | 0/32 | 0% | 0% |
| DeBERTa raw | 8/32 | 1/32 | 25% | 3.125% |

Task-only и shipped выбрали all-negative operating point (`no_alerts`). Это не
успех защиты. Context получил больше срабатываний, включая лишние: на таком числе
семейств нельзя объявлять его лучше payload-only или DeBERTa. У raw references
нет задачи пользователя; условия входа различаются и раскрыты в отчёте.

**Authorization-pairs:** ни одна модель не классифицировала правильно обе строки
хотя бы одной из 4 языковых test-пар (одного независимого семейства). Context
поставил атаке больший score лишь в 2/4 пар. Добавить задачу в JSON оказалось
недостаточно, чтобы линейная модель надёжно поняла разрешения.

Сканер strict/tool-result отдельно: sanitize/block для 3/32 атак, FP=0/32.
Это наблюдаемые действия сканера, не успешность защиты агента.

Python/Go максимальная разница: context `1.6653345369377348e-16`, payload-only
`2.220446049250313e-16`, task-only `1.1102230246251565e-16`.

Полный локальный report содержит thresholds, per-type/per-language metrics,
хеши моделей/tokenizer/runtime, cluster intervals и predictions; данные и веса
не дублируются в Git. Воспроизведение — [contextual.md](contextual.md).

Метки и переводы ожидают независимой проверки человеком. Нет иных авторов,
естественных документов и agent harness. Test использован только для этого отчёта;
подбор новых моделей/гиперпараметров по этим числам сделает его development-набором
и потребует новых независимых test-семейств. Production-веса/пороги не изменены.
